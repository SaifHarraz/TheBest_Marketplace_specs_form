# أداة تصميم تجربة المتجر وتحديد نطاق المرحلة الأولى
## Interactive E-commerce Client Journey & Feature Selection Builder

أداة تفاعلية متكاملة موجّهة لاجتماعات العمل مع أصحاب الأعمال والبراندات (Brand Owners) للتخطيط للمرحلة الأولى (Phase 1) من متجرهم الإلكتروني، وتحديد متطلباتهم، واستعراض شجرة رحلة العميل خطوة بخطوة، وحفظ أو إرسال المتطلبات مباشرة.

---

### المميزات الرئيسية
1. **واجهة باللغة العربية والإنجليزية (Bilingual RTL/LTR):** لغة عربية احترافية مبسطة مناسبة لأصحاب الأنشطة التجارية في مصر والعالم العربي مع إمكانية التبديل الفوري للإنجليزية.
2. **شجرة رحلة العميل التفاعلية (Interactive Flowchart):** 9 مراحل رئيسية (A إلى I) مع مسارات اتخاذ القرار (Decision Points) والمسارات البديلة، وتتفاعل تلقائياً مع خيارات العميل للميزات.
3. **كتالوج الميزات الشامل (12 قسماً و151 ميزة):** خيارات واضحة (مطلوب، اختياري، غير مطلوب، لم يحدد) مع فلترة وبحث وتنبيهات الاعتماديات (Dependencies).
4. **متطلبات مخصصة:** إمكانية إضافة أفكار خاصة بالنشاط التجاري مع تحديد أولويتها.
5. **المراجعة والتأكيد النهائي:** شاشة مراجعة متكاملة توضح الإحصائيات، تنبيهات التوافق، ومربع تأكيد قانوني مبدئي.
6. **تكامل كامل مع Formspree:** إرسال المتطلبات بنقرة واحدة عبر HTTP POST مع حالات التحميل والنجاح والخطأ.
7. **الحفظ التلقائي والتصدير:** حفظ مستمر في `localStorage`، تصدير واستيراد ملفات `JSON`، وتنسيق مخصص للطباعة وحفظ كملف `PDF`.

---

### طريقة التشغيل محلياً (How to Run Locally)

1. **التشغيل المباشر في المتصفح:**
   - انقر مرتين على ملف [`index.html`](file:///c:/Users/Saif/Desktop/TheBest%20E-commerce%20specs%20form/index.html) لفتحه مباشرة في أي متصفح (Google Chrome، Microsoft Edge، Safari، Firefox).

2. **أو التشغيل عبر خادم محلي (Local HTTP Server):**
   ```bash
   npx serve .
   ```
   أو عبر بايثون:
   ```bash
   python -m http.server 8080
   ```
   ثم افتح المتصفح على: `http://localhost:8080`

### ضبط مفتاح Formspree (Formspree Configuration)

في السطر رقم 317 تقريباً داخل ملف [`index.html`](file:///c:/Users/Saif/Desktop/TheBest%20E-commerce%20specs%20form/index.html):
```javascript
const FORMSPREE_ENDPOINT = "https://formspree.io/f/YOUR_FORM_ID";
```
استبدل `YOUR_FORM_ID` بمعرف النموذج الخاص بك من حساب [Formspree](https://formspree.io).

### تصدير واستعادة مسودات العملاء
- **تصدير مسودة:** من قائمة "المسودة والملف" بأعلى الشاشة، انقر على **"تصدير ملف المشروع (JSON)"**.
