# أداة تصميم تجربة المتجر وتحديد نطاق المرحلة الأولى
## Interactive E-commerce Client Journey & Feature Selection Builder

أداة تفاعلية متكاملة موجّهة لاجتماعات العمل مع أصحاب الأعمال والبراندات (Brand Owners) للتخطيط للمرحلة الأولى (Phase 1) من متجرهم الإلكتروني، وتحديد متطلباتهم، واستعراض شجرة رحلة العميل خطوة بخطوة، وحفظ المسودات، وإرسال المتطلبات المكتملة مباشرة إلى بريدك الإلكتروني عبر خدمة **Web3Forms**.

---

### المميزات الرئيسية
1. **تكامل Web3Forms لاستلام المتطلبات بالبريد:**
   - إرسال متكامل عبر API خدمة Web3Forms الرسمية.
   - يتضمن البريد المرسل: بيانات العميل، ملخص النشاط، جدول الميزات المطلوبة والاختيارية مصنفة حسب الأقسام، المتطلبات المخصصة، تكوين شجرة رحلة العميل النشطة، وتنبيهات الاعتماديات، بالإضافة إلى كائن JSON كامل لسهولة الاستيراد البرمجي.
2. **واجهة باللغة العربية والإنجليزية (Bilingual RTL/LTR):** لغة عربية احترافية مبسطة مع إمكانية التبديل الفوري للإنجليزية وحفظ تفضيل اللغة.
3. **شجرة رحلة العميل التفاعلية (Interactive Flowchart):** 9 مراحل رئيسية (A إلى I) مع نقاط القرار (Decision Points) والمسارات البديلة متفاعلة تلقائياً مع خيارات الميزات.
4. **كتالوج الميزات الشامل (12 قسماً و151 ميزة):** خيارات واضحة (مطلوب، اختياري، غير مطلوب، لم يحدد) مع فلترة وبحث وتنبيهات الاعتماديات (Dependencies).
5. **متطلبات مخصصة:** إمكانية إضافة أفكار خاصة بالنشاط التجاري مع تحديد أولويتها.
6. **المراجعة والتأكيد النهائي:** شاشة مراجعة متكاملة توضح الإحصائيات، تنبيهات التوافق، ومربع تأكيد قانوني مبدئي.
7. **الحفظ التلقائي والتصدير:** حفظ مستمر في `localStorage`، تصدير واستيراد ملفات `JSON`، وتنسيق مخصص للطباعة وحفظ كملف `PDF`.

### طريقة التشغيل محلياً (How to Run Locally)

1. **التشغيل المباشر في المتصفح:**
   - انقر مرتين على ملف [`index.html`](file:///c:/Users/Saif/Desktop/TheBest%20E-commerce%20specs%20form/index.html) لفتحه مباشرة في أي متصفح (Google Chrome، Microsoft Edge، Safari، Firefox).

2. **أو التشغيل عبر خادم محلي (Local HTTP Server):**
   ```bash
   npx serve .
   ```
   أو عبر بايثون:
   ```bash
   python -m http.server 8080
   ```
   ثم افتح المتصفح على: `http://localhost:8080`

3. **إعادة بناء أو تجميع التطبيق (Build):**
   - لتجميع التطبيق بعد تعديل البيانات في `features_data.js` أو `journey_data.js`:
   ```bash
   npm run build
   ```
   أو:
   ```bash
   node build.js
   ```

### خطوات ضبط واستلام الطلبات عبر Web3Forms (Setup Web3Forms)

1. **الحصول على مفتاح الوصول (Access Key):**
   - ادخل على موقع [Web3Forms](https://web3forms.com/).
   - اكتب بريدك الإلكتروني الذي تريد استلام متطلبات العملاء عليه في خانة "Create Your Access Key".
   - اضغط **Create Access Key**؛ سيصلك بريد فوري يحتوي على المفتاح الخاص بك (يبدأ عادةً بحروف وأرقام مثل: `a1b2c3d4-e5f6-...`).

2. **وضع المفتاح في الكود:**
   - افتح ملف [`index.html`](file:///c:/Users/Saif/Desktop/TheBest%20E-commerce%20specs%20form/index.html).
   - ابحث عن السطر رقم **348** تقريباً:
     ```javascript
     const WEB3FORMS_ACCESS_KEY = "YOUR_ACCESS_KEY_HERE";
     ```
   - استبدل `"YOUR_ACCESS_KEY_HERE"` بمفتاحك الحقيقي، ليصبح مثلاً:
     ```javascript
     const WEB3FORMS_ACCESS_KEY = "a1b2c3d4-e5f6-7890-abcd-ef1234567890";
     ```
   - احفظ الملف.

3. **التحقق وتجربة الإرسال:**
   - افتح الصفحة في المتصفح، وانتقل للمرحلة 4 (المراجعة).
   - أدخل اسم عميل، بريد تجريبي، واسم براند.
   - تأكد من التأشير على مربع التأكيد ثم اضغط **"حفظ الاختيارات وإرسال المتطلبات عبر البريد"**.
   - ستظهر حالة التحميل، وفور استجابة Web3Forms بالنجاح ستظهر رسالة التأكيد الخضراء وسيصلك بريد فوري بكامل متطلبات وتفاصيل المشروع.

### ما يصلك في البريد الإلكتروني:
- **عنوان البريد:** `New E-commerce Project Requirements — [اسم البراند] [PRJ-xxxx-xxxx]`
- **بيانات العميل:** الاسم، البريد (Reply-To مضبوط على بريد العميل للرد المباشر عليه)، الهاتف/واتساب.
- **ملخص المشروع:** الهدف من المتجر، الجمهور المستهدف، عدد المنتجات المقدر، اللغة المفضلة.
- **قائمة الميزات المطلوبة:** مقسمة ومفصلة لكل تصنيف مع الأكواد المستقرة والأسماء بالعربية والإنجليزية.
- **قائمة الميزات الاختيارية والمستبعدة والمتطلبات المخصصة.**
- **مسار رحلة العميل النشط:** المحطات المعتمدة (صفحات، قرارات، دفع، شحن، تتبع).
- **كائن JSON الكامل (`complete_project_json`):** متاح داخل البريد لنسخه واستيراده مباشرة في أي وقت لاحق عبر زر "استيراد ملف مشروع (JSON)".
